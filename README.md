# Hayedo Rural · Proyecto web del certificado IFCD0210

Proyecto integrador del curso. Empresa **ficticia**: todos los datos son inventados.

## Primeros pasos (sesión 2)

1. En esta página pulsa **Use this template › Create a new repository**.
2. *Owner*: **tu cuenta**. *Repository name*: `hayedo-rural-<tu-usuario>`. Visibilidad: **Private**. Pulsa **Create repository**.
3. En tu repositorio nuevo: **Settings › Collaborators › Add people** e invita a tu docente (su usuario está en el aula virtual).
4. Copia la dirección de tu repositorio (botón verde **Code › HTTPS**) y pégala en la tarea del aula virtual.
5. En VS Code: `Ctrl+Mayús+P` › **Git: Clonar** › pega la dirección › elige una carpeta › **Abrir**.

## Cada día de clase

- **Al empezar:** en VS Code, panel *Control de código fuente* (`Ctrl+Mayús+G`) › **Sincronizar cambios**. Así recibes los archivos que publique tu docente para la sesión.
- **Mientras trabajas:** guarda, prepara (**+**), escribe un mensaje claro y **Confirmar** (commit).
- **Al terminar:** **Sincronizar cambios** otra vez para subir tu trabajo (push).

## Normas

- Abre siempre **la carpeta** del proyecto en VS Code, no un archivo suelto. Live Server: clic derecho en `index.html` › **Open with Live Server**.
- Nombres de archivo en minúsculas, sin espacios ni tildes (`casa-los-tejos.html`).
- IA: primero sin IA; después contrasta y anota qué aceptas y por qué. Nunca pegues datos personales reales.
